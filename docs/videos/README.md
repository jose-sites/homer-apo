# Vídeos reais da aplicação

Gravados em Chromium na nuvem, em 360×640, com renderização WebGL por software e qualidade baixa. Sem APIs, TikTok conectado ou áudio de IA/TTS. A baixa taxa de renderização nesta máquina (aproximadamente 2 FPS nas amostras) limita a fluidez; não é uma medição do desempenho no Windows com GPU.

- `normal.mp4`: 18 segundos na sala.
- `rosquinha.mp4`: 42 segundos, incluindo a sequência de 38 segundos.
- `irl.mp4`: 65 segundos de passeio com câmera de selfie. É um trecho inicial, não um tour completo dos 16 cômodos.

Capturas contínuas da aplicação em execução; não são imagens geradas ou animações pré-renderizadas. Os trechos de carregamento inicial foram removidos. Código de referência: ebf3671.
